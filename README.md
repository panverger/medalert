# medalert
Χώρος για τον 8ο Διαγωνισμό Ανοικτών Τεχνολογιών στην Εκπαίδευση με θέμα: Σύστημα αυτόματης ειδοποίησης και παρακολούθησης λήψης φαρμάκων με υποστήριξη απομακρυσμένου φροντιστή

Μη χρήση Οξύμετρου λόγω μη έγκυρων μετρήσεων

Θα πρέπει να μπει και ηχητική ειδοποίηση με δοκιμή μάλλον σύνδεσης πάνω στο Arduino Uno Q ηχείων bluetooth
